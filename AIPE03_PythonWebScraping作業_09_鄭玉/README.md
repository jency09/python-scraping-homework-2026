# 漫畫網站爬蟲練習

這是根據課堂講義延伸實作的 Python 爬蟲專案。本專案旨在練習網路爬蟲的核心技術，並將實作成果整理於此 GitHub 儲存庫中。

## 專案簡介
本練習主要針對漫畫網站進行資料抓取，包含自動化網頁操作、解析 HTML 結構以及處理動態載入的內容。透過此專案，我實踐了從網頁請求到資料儲存的完整流程。

## 技術重點
* **環境管理**：使用 `requirements.txt` 管理專案依賴套件。
* **網頁解析**：利用 `BeautifulSoup` 或 `lxml` 處理靜態頁面標籤。
* **動態內容處理**：使用 `Selenium` 模擬瀏覽器行為，處理 JavaScript 渲染的漫畫圖片。
* **Session 與 Cookie 管理**：練習處理登入驗證與維持連線狀態，確保抓取過程不中斷。
* **檔案存取**：將抓取到的漫畫圖片自動分類存檔。

## 檔案結構
* `main.py`: 爬蟲主程式邏輯。
* `utils.py`: 存放通用工具函數（如連線設定、格式化輸出）。
* `requirements.txt`: 專案所需的套件清單。
* `data/`: 爬取結果的預設儲存目錄。

## 使用說明
1.  複製此專案到本地端。
2.  安裝必要套件：`pip install -r requirements.txt`。
3.  確認已安裝對應瀏覽器的 WebDriver（若使用 Selenium）。
4.  執行 `python main.py` 開始練習。
